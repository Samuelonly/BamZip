# BamZip

**拖进来就办。**

BamZip 是一款为 macOS 打造的极速压缩与解压工具：把文件拖进窗口，剩下的交给它。

## 核心能力

- **压缩** — 一步打包，自动选择合适格式
- **解压** — 拖入即解，无需翻找菜单
- **ISO / DMG 一键安装** — 挂载、安装、清理一步到位
- **GBK 乱码还原** — 自动修复中文文件名乱码
- **Blink Mode** — 极简一闪而过，不打断手头的事
- **免密看清单** — 加密包无需输入密码即可预览内容
- **加密与分卷** — 支持密码保护与分卷压缩

- Apple Silicon（arm64）
